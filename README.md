# Crochet by Alae

موقع "Crochet by Alae" — متجر إلكتروني كامل الوظائف (React + Tailwind + Supabase)، بتصميم "Stitch & Soul" (نسخة معاد تصميمها عبر Google Stitch، أكثر تميزاً وإبداعاً من النسخة الأولى).

## ✅ الحالة: المشروع مكتمل بالكامل، بالتصميم الجديد

**الصفحات العامة (للزبونة):**
- الرئيسية، المتجر (بفلترة حسب الفئة)، صفحة المنتج (ألوان/مقاسات/ملاحظات + إضافة للسلة)
- السلة والطلب النهائي (نموذج كامل + إرسال عبر القناة المختارة)
- صفحة طلب تصميم مخصص (وصف حر + رفع صورة مرجعية)
- صفحة "من نحن"

**لوحة تحكم الأدمن (محمية بتسجيل دخول):**
- نظرة عامة (إحصائيات)
- إدارة المنتجات (إضافة/تعديل/حذف، رفع صور متعددة، تحكم بظهور السعر لكل منتج)
- إدارة الطلبات (تغيير الحالة: جديد/قيد التحضير/تم الشحن/تم التوصيل)
- إدارة طلبات التصميم المخصص (تغيير الحالة)
- قائمة العملاء
- الإعدادات: قنوات التواصل (تفعيل/تعطيل/تعديل الروابط لكل من واتساب، انستغرام، هاتف، تيك توك)، رفع/تغيير الشعار، تفعيل/تعطيل تنبيه منطقة التوصيل، اللغة والمظهر الافتراضيين

**ميزات مطبقة عبر كل الموقع:**
- ثنائية اللغة عربي (RTL) / إنجليزي (LTR) — قابلة للتبديل من الهيدر
- الوضع الفاتح / الداكن — قابل للتبديل من الهيدر
- تنبيه جغرافي (Geo-banner): يظهر فقط للزوار من خارج ولايتي البليدة والجزائر العاصمة، بدون حجب التصفح، ويتحكم الأدمن بإظهاره من عدمه
- توجيه الطلبات ديناميكياً حسب القنوات المفعّلة من الأدمن: واتساب (رسالة معبأة تلقائياً)، انستغرام (نسخ للحافظة)، اتصال مباشر
- سلة تسوق تُحفظ محلياً (localStorage) وتبقى بين الزيارات

## بنية المشروع
```
src/
  components/     Header, Footer, GeoBanner, ProductCard
  pages/          الصفحات العامة (Home, Shop, ProductDetail, CartCheckout, CustomRequest, About, AdminLogin)
  pages/admin/    لوحة التحكم (AdminLayout + 6 لوحات فرعية)
  i18n/           قاموس الترجمة الكامل AR/EN + LanguageContext (كل النصوص من هنا، بلا نص مكتوب مباشرة)
  lib/            Supabase client، السلة (CartContext)، تسجيل دخول الأدمن (AuthContext)، الوضع الداكن (ThemeContext)،
                  تحديد الموقع الجغرافي (useGeoBanner)، توجيه الطلبات (contactChannels)، رفع الصور (storage)
supabase/
  schema.sql      قاعدة البيانات كاملة + سياسات الأمان (RLS) + سياسات التخزين (Storage)
design-reference/ ملفات تصميم Stitch الأصلية (للرجوع إليها عند الحاجة)
```

## خطوات النشر الكاملة (بالترتيب، مجاناً بالكامل — بلا بطاقة بنكية فأي خطوة)

### 1) إعداد Supabase (قاعدة البيانات + تسجيل دخول الأدمن + تخزين الصور)
1. سجلي فـ [supabase.com](https://supabase.com) (تسجيل مجاني، بلا بطاقة).
2. أنشئي مشروع جديد (New Project) — اختاري كلمة سر قوية لقاعدة البيانات واحفظيها.
3. من القائمة الجانبية، روحي لـ **SQL Editor** → **New query**، وانسخي محتوى ملف `supabase/schema.sql` بالكامل والصقيه، واضغطي **Run**.
   - هذا ينشئ كل الجداول (المنتجات، الطلبات، طلبات التصميم المخصص، قنوات التواصل، الإعدادات، العملاء) وكل سياسات الأمان دفعة واحدة.
4. من **Storage**، اضغطي **New bucket**، سميه بالضبط `product-images`، وفعّلي خيار **Public**. (سياسات الوصول لهذا الـ bucket تكون مُعدّة أصلاً من الخطوة 3.)
5. من **Authentication → Users**، اضغطي **Add user** وأنشئي مستخدم واحد (بريدك الإلكتروني + كلمة سر) — هذا هو حساب دخول الأدمن اللي غادي تستعمليه فـ `/admin/login`.
6. من **Project Settings → API**، انسخي القيمتين: **Project URL** و **anon public key** — غادي نحتاجوهم فالخطوة الجاية.

### 2) إعداد إيميل تنبيه الطلبات (EmailJS — مجاني، بلا بطاقة، اختياري)
كل ما توصل طلب جديد، الموقع يبعثلك إيميل تنبيه لبريدك الشخصي، وإذا الزبونة كتبت بريدها فـ الطلب، تقدري تردي عليها مباشرة بالضغط على "Reply".
1. سجلي فـ [emailjs.com](https://www.emailjs.com) (مجاني، بلا بطاقة).
2. **Email Services → Add New Service** → اختاري Gmail (أو أي بريد عندك) واربطيه.
3. **Email Templates → Create New Template** — فـ خانة **To Email** حطي بريدك اللي تحبي تستقبلي فيه التنبيهات. فـ محتوى القالب (Subject/Body) استعملي بالضبط هاذو المتغيرات:
   ```
   Subject: طلب جديد من {{customer_name}}

   الاسم: {{customer_name}}
   الهاتف: {{customer_phone}}
   البريد: {{customer_email}}
   البلدية: {{commune}}
   العنوان: {{address}}
   تفاصيل الطلب: {{order_summary}}
   المجموع: {{total}}
   ```
   وفـ خانة **Reply To** حطي `{{reply_to}}` (هكاك إذا رديتي على الإيميل، يروح للزبونة مباشرة).
4. من **Account → General**، انسخي الـ **Public Key**.
5. زيدي الثلاثة قيم فـ `.env` (محلياً) و فـ Environment variables متاع Netlify (خطوة 4.4 تحت (Netlify)): Service ID، Template ID، Public Key.

> إذا ما حبيتيش هاذ الميزة دابا، خليها فارغة فـ `.env` — الموقع يخدم عادي بلاها (بس بلا إيميلات تنبيه).

### 3) رفع المشروع لـ GitHub
```bash
cd crochet-by-alae
git init
git add .
git commit -m "Initial commit — Crochet by Alae"
```
أنشئي مستودع (repository) جديد فـ GitHub (فارغ، بلا README)، بعدها:
```bash
git remote add origin https://github.com/USERNAME/crochet-by-alae.git
git branch -M main
git push -u origin main
```

### 4) النشر عبر Netlify (مجاني، ويسمح بالمواقع التجارية خلافاً لـ Vercel)
1. سجلي فـ [netlify.com](https://netlify.com) بحساب GitHub.
2. **Add new site → Import an existing project → GitHub** → اختاري مستودع `crochet-by-alae`.
3. إعدادات البناء (Build settings):
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
4. قبل الضغط على Deploy، افتحي **Environment variables** وزيدي:
   - `VITE_SUPABASE_URL` = القيمة اللي نسختيها من Supabase
   - `VITE_SUPABASE_ANON_KEY` = القيمة اللي نسختيها من Supabase
   - (إذا فعّلتي إيميل التنبيه) `VITE_EMAILJS_SERVICE_ID`، `VITE_EMAILJS_TEMPLATE_ID`، `VITE_EMAILJS_PUBLIC_KEY`
5. اضغطي **Deploy site**. بعد دقيقة أو دقيقتين يعطيك Netlify رابط مباشر للموقع (يقدر تبدليه لدومين مخصص لاحقاً من إعدادات Netlify، مازال مجاني).
6. من الآن، كل مرة تديري فيها `git push` لـ GitHub، Netlify يعيد بناء ونشر الموقع أوتوماتيكياً.

### 5) أول استعمال بعد النشر
1. روحي لـ `رابط-موقعك.netlify.app/admin/login` وسجلي دخول بالحساب اللي أنشأتيه فالخطوة 1.
2. من **إعدادات الموقع (Site Settings)**: زيدي قنوات التواصل (رقم الواتساب، رابط انستغرام DM...) وفعّليهم.
3. من **المنتجات**: أضيفي أول منتج (اسم، وصف، صور، ألوان، مقاسات، وحددي إذا يظهر السعر أم لا).
4. زوري الموقع من صفحة التصفح العادية وجربي: تبديل اللغة، الوضع الداكن، إضافة منتج للسلة، وإرسال طلب تجريبي.

## التشغيل محلياً (اختياري، إذا حبيتي تجربي أو تعدلي قبل النشر)
```bash
npm install
cp .env.example .env   # وحطي فيه القيم الحقيقية (Supabase و EmailJS إذا حبيتي)
npm run dev
```

## ملاحظات تقنية مهمة
- **تحديد الموقع الجغرافي**: يعتمد على خدمة IP geolocation مجانية (`ipapi.co`) — دقتها جيدة لكن غير مضمونة 100%، ولذلك صُمم النظام ليكون "متسامحاً": إذا تعذّر التحديد، لا يظهر أي تنبيه (بدل تنبيه خاطئ). مناطق التوصيل الحالية هي ولايتا البليدة والجزائر العاصمة.
- **قاعدة بيانات Supabase المجانية**: تتوقف مؤقتاً (Pause) إذا بقى المشروع بلا أي طلب لمدة 7 أيام متتالية — إذا صار هذا، رسالة فـ لوحة Supabase تسمحلك تعيدي تشغيله بضغطة واحدة (Resume)، ولا يأثر على بياناتك.
- **الأمان**: كل الجداول الحساسة (الطلبات، طلبات التصميم المخصص، الإعدادات) محمية بسياسات RLS تمنع أي شخص غير مسجل دخول (غير الأدمن) من قراءتها أو تعديلها.
